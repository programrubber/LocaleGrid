# Skill & Rule Authoring Guidelines

## Principles of Durable Rules
1. **Enforce Structural Rules**: Prefer explicit structural or file placement checks over subjective prompts.
2. **Respect Existing Taxonomy**: Before proposing a new rule, verify if it fits into existing sections of `AGENTS.md`.
3. **Language Rule**: Keep instructions concise, and ensure that all human-facing summaries are presented in Korean.
