# LocaleGrid 릴리즈 노트

## 0.17.0 - 2026-09-08

### 변경 사항
- 모든 언어 값이 빈 행에서는 상황을 설명해 UI 문구를 추천받을 수 있습니다. 기존 값이 있는 행은 해당 값을 참고해 빈 언어의 번역을 제안합니다.
- 자동·라벨형·문장형에 네트워크 관리 웹 UI 지침을 적용했습니다. 원문이나 요청에 없는 실패 원인, 계정 잠금 정책, 잔여 횟수를 임의로 추가하지 않도록 했습니다.
- 후보를 다국어 [A안]·[B안]·[C안] 세트로 제공합니다. 명확한 문구는 1개를 우선하고 유용한 대안이 있을 때만 최대 3개를 제안합니다.
- 어느 언어에서 안을 선택하면 해당 언어에만 적용하며, 다른 언어에는 같은 안의 칩만 남습니다. 다른 언어는 각각 클릭해 적용합니다. 필요한 언어가 빠진 세트는 제외하고, 닫기 버튼은 해당 후보만 제거합니다.
- AI 영역을 `자동·라벨형·문장형 → 입력창 → AI 번역 제안` 순서로 배치했습니다. 입력창 기본 너비는 360px이며, 긴 후보와 좁은 화면의 줄바꿈을 지원합니다.
- 입력창의 플레이스홀더와 툴팁을 개선했습니다. 요청 내용은 파일에 저장하지 않으며, 행 전환 시 초기화하고 요청 중에는 입력을 잠급니다.

### 검증
- macOS / JDK 17에서 clean 빌드로 전체 130개 테스트와 플러그인 ZIP 빌드를 통과했습니다. ZIP 무결성, 버전·한국어 설명과 로컬 배포본 SHA-256 일치를 확인했습니다.
- 로컬 oMLX/Qwen3.5-9B-6bit에서 상황 설명에 따른 문구 생성과 다국어 세트 응답을 확인했습니다. 결과의 표현과 개수는 모델에 따라 달라질 수 있습니다.
- 후보 선택·개별 닫기·다국어 안 유지 및 헤더 배치를 자동 테스트로 확인했으며, Swing 렌더링으로 입력창과 칩 배치를 점검했습니다.
- Windows·HiDPI 실환경과 사내 폐쇄망 AI 서버는 검증하지 않았습니다.

## 0.16.0 - 2026-09-07

### 변경 사항
- AI 번역 제안에 `자동`·`라벨형`·`문장형` 스타일 선택을 추가했습니다. 자동은 원문의 표현 형태에 맞춰 번역하고, 라벨형은 길이 제한이나 의미 축약 없이 버튼·메뉴·항목명에 맞게 표현합니다.
- AI 실행 버튼과 스타일 옵션을 하나의 보라색 영역으로 통합했습니다. 전체 높이는 28px, 내부 버튼은 24px로 줄였으며 DPI 배율을 적용합니다.
- 선택은 현재 에디터에서 유지되고, 다시 열면 자동으로 시작합니다. 요청 중에는 스타일과 실행 버튼을 비활성화하며 좌우 방향키로 스타일을 선택할 수 있습니다.
- 좁은 화면에서는 키명을 윗줄에 배치하고, 기존 번역 제안 칩·플레이스홀더 보존·JSON 응답 규칙을 유지합니다.

### 검증
- macOS / JDK 17 환경에서 전체 123개 테스트 및 플러그인 ZIP 빌드를 확인했습니다.
- 개발 PyCharm의 실제 UI를 직접 렌더링해 선택 상태와 좁은 화면 배치를 확인했습니다.
- Windows·HiDPI 실환경과 사내 AI 서버의 번역 품질은 이번 릴리즈에서 검증하지 않았습니다.

## 0.15.0 - 2026-09-07

### 변경 사항
- 사내 AI 번역 제안의 활성화 여부, 엔드포인트, 모델, API Key, 타임아웃을 IDE 전체 프로젝트가 공유하도록 변경했습니다.
- 설정 화면에 모든 프로젝트 공통임을 표시하고, 적용 시 열린 프로젝트의 AI 번역 제안 버튼에 반영합니다.
- 글로벌 설정이 없으면 처음 발견한 사용자 지정 프로젝트 AI 설정을 한 번 가져옵니다. 이후 다른 프로젝트의 기존 설정으로 덮어쓰지 않습니다.
- locale 경로, 표시 순서, 예외 키, 들여쓰기와 문자 체계 검사는 기존처럼 프로젝트별로 유지합니다.

### 검증
- macOS / JDK 17 환경에서 전체 121개 테스트 통과 및 플러그인 ZIP 빌드를 확인했습니다.
- Windows 및 여러 프로젝트를 연 실제 IDE 동작, 사내 AI 서버 연결은 이번 릴리즈에서 검증하지 않았습니다.

## 0.14.0 - 2026-09-06

### 변경 사항
- 검색창에서 위·아래 방향키와 Enter/Shift+Enter로 이전·다음 검색 결과를 탐색할 수 있습니다.
- 테이블에 포커스가 있을 때 F3/Shift+F3로 다음·이전 검색 결과를 탐색할 수 있습니다.
- 검색창과 탐색 버튼의 툴팁에 단축키 안내를 추가했습니다.
- 검색창 키 바인딩과 검색 결과의 양방향 순환 탐색에 대한 회귀 테스트를 추가했습니다.
- OpenAI 호환 사내·로컬 LLM 연결 설정과 연결 테스트, 입력된 언어를 참고한 빈 언어 항목의 AI 번역 제안을 추가했습니다.
- Qwen의 thinking 출력을 비활성화하고 JSON 응답을 요청하며, 지원하지 않는 옵션의 호환 처리와 잘린 응답 진단을 개선했습니다.
- 번역 제안은 작은 아이콘 칩으로 표시하며 클릭 또는 Enter/Space로 적용할 수 있습니다. 긴 문구는 한 줄 말줄임과 전체 문구 툴팁을 제공합니다.
- 모든 언어가 입력되어 있으면 AI 번역 제안 버튼이 비활성화됩니다. AI 안내는 버튼 바로 오른쪽에 같은 크기의 글꼴로 표시하며, 기존 하단 상태 정보는 유지합니다.
- JSON 로드·저장 시 가상 파일의 유효성 확인과 파일 시스템 갱신 처리를 보완했습니다.

### 검증
- macOS / JDK 17 환경에서 전체 117개 테스트 및 플러그인 ZIP 빌드를 검증했습니다.
- PyCharm Community 2023.3.5 개발 IDE에서 플러그인 로드를 확인했습니다. Windows 및 사내 폐쇄망 실환경 검증은 별도입니다.

## 0.13.0 - 2026-08-18

### 변경 사항
- 확대 글꼴과 HiDPI 환경에서도 추가, 편집, 삭제 등 상단 작업 버튼의 아이콘과 라벨이 잘리지 않도록 크기 계산을 개선했습니다.
- 표시 열이 적을 때 테이블이 남는 화면 폭을 채우도록 개선하고, 열이 많을 때는 기존 가로 스크롤을 유지합니다.
- 확대 글꼴과 아이콘 조합의 버튼 라벨 및 테이블 폭 동작에 대한 회귀 테스트를 추가했습니다.

## 0.12.0 - 2026-08-05

### 변경 사항
- 개발 및 배포 대상을 PyCharm Community Edition으로 전환했습니다.
- 검색 입력 debounce를 500ms로 조정해 입력 중 테이블 갱신 부담을 줄였습니다.
- 상태 필터 버튼을 더 작게 다듬고, 행 작업 버튼에 동작을 나타내는 아이콘을 추가했습니다.
- 예외키와 설정 버튼을 아이콘 및 라벨 조합으로 통일하고 상단 버튼의 외곽선을 정리했습니다.

## 0.11.0 - 2026-08-05

### 변경 사항
- 검색 기본 동작을 전체 Row 유지와 매칭 텍스트 하이라이트로 변경했습니다.
- 매칭 Row 기준 검색 건수와 순환형 이전·다음 탐색, 선택형 검색 결과 필터를 추가했습니다.
- 검색과 상세 value 편집 갱신에 debounce를 적용해 연속 입력 성능을 개선했습니다.

## 0.10.0 - 2026-07-24

### 변경 사항
- 여러 상태 필터를 동시에 선택하면 하나라도 일치하는 행을 표시하도록 OR 조건으로 변경했습니다.
- 검색어 필터는 선택한 상태 필터 결과를 계속 좁혀서 표시합니다.

## 0.9.0 - 2026-07-24

### 변경 사항
- locale별 허용 문자 체계를 검사해 다른 언어의 문자가 섞인 번역을 진단하도록 추가했습니다.
- 한국어, 영어, 일본어, 베트남어를 명시적으로 지원하고, 그 외 locale은 CLDR 및 BCP 47 script 정보를 기반으로 판정합니다.
- 문자 체계 검증의 warning/저장 차단 정책을 설정에서 선택할 수 있으며, 그리드 상태와 툴팁에서 위반 문자를 확인할 수 있습니다.

## 0.8.0 - 2026-06-30

### 변경 사항
- 검색 결과에서 매칭된 텍스트를 선명한 하이라이트로 표시하도록 개선했습니다.

## 0.7.0 - 2026-06-01

### 변경 사항
- 플러그인 로고를 원본 이미지 기반 아이콘으로 교체.

## 0.6.0 - 2026-05-31

### 변경 사항
- 플러그인 상세 설명의 깨진 한국어 문구를 UTF-8 기준으로 복구했습니다.
- 릴리즈 ZIP 내부 `META-INF/plugin.xml`에서 한국어 설명이 정상 출력되는지 확인했습니다.
